# Imágenes y evidencias gráficas

Esta carpeta está destinada a recopilar las evidencias gráficas relacionadas con el desarrollo del proyecto **EcoTech Hybrid**.

## Contenido previsto

Se podrán incorporar fotografías y recursos gráficos relacionados con:

* Proceso de diseño.
* Construcción del prototipo.
* Montaje del sistema.
* Experimentación con Arduino.
* Sensorización.
* Cultivo hidropónico.
* Instalación fotovoltaica.
* Actividades realizadas por el alumnado.
* Trabajo interdisciplinar.
* Presentaciones y exposiciones.
* Prototipos y resultados.

## Criterios de organización

Las imágenes deberán identificarse de forma clara para facilitar su relación con las diferentes fases del proyecto.

Cuando sea necesario, se incluirá una breve descripción de cada evidencia indicando:

* Qué se muestra.
* Fase del proyecto.
* Actividad realizada.
* Participantes o grupo, cuando proceda.
* Fecha aproximada.

Las imágenes se incorporarán respetando las autorizaciones y condiciones de uso correspondientes.
