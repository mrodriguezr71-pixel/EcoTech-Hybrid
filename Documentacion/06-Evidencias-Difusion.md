# Evidencias y difusión

## 1. Finalidad

Este documento recoge y organiza las principales evidencias que permiten comprobar el desarrollo, los resultados y la difusión del proyecto **EcoTech Hybrid – Innovación Verde para un Futuro Sostenible**.

El repositorio no pretende únicamente almacenar documentación, sino facilitar la **trazabilidad del proyecto**, permitiendo relacionar las actuaciones realizadas con sus evidencias técnicas, educativas y de difusión.

---

Entre ellas se incluyen:

* Configuración y utilización de sensores.
* Sistemas de adquisición de datos.
* Pruebas de automatización y control.
* Documentación de conexiones y componentes.
* Desarrollo y evolución del prototipo.
* Integración de soluciones relacionadas con la generación fotovoltaica.
* Fotografías del montaje, pruebas y proceso constructivo.
* Documentación técnica generada durante el proyecto.

### Ubicación principal

* `Arduino/`
* `Sensores/`
* `Imagenes/`
* `Documentacion/`

La documentación técnica podrá ampliarse progresivamente a medida que se incorporen nuevos desarrollos y mejoras al prototipo.

## 5. Evidencias del proceso

La documentación del proyecto permite visualizar diferentes momentos del proceso:

**Reto → Diseño → Desarrollo → Integración → Pruebas → Mejora → Comunicación**

Este enfoque permite evidenciar no solamente el resultado final, sino también el proceso de aprendizaje y de desarrollo tecnológico seguido hasta alcanzarlo.

---

## 9. Criterios para incorporar evidencias

Para que una evidencia sea útil deberá, siempre que sea posible:

1. Identificar qué actividad demuestra.
2. Estar relacionada directamente con el proyecto.
3. Permitir situarla temporalmente.
4. Mostrar el proceso o el resultado de forma comprensible.
5. Mantener una organización coherente dentro del repositorio.
6. Respetar la privacidad y protección de datos del alumnado.
7. Evitar la incorporación de información personal innecesaria.

En el caso de fotografías o vídeos en los que aparezca alumnado, se utilizarán únicamente aquellos materiales que puedan difundirse conforme a las autorizaciones y normas aplicables.

---

## 10. Estado de las evidencias

Para facilitar la actualización del repositorio se utilizarán tres estados:

* **Disponible:** la evidencia ya está incorporada.
* **Pendiente:** la evidencia existe o está prevista, pero todavía no se ha incorporado.
* **Por completar:** requiere generar o recopilar la evidencia.

Este sistema permite mantener el repositorio actualizado sin confundir documentación pendiente con evidencias ya disponibles.

La estructura del repositorio permite relacionar:

**Actividad → Desarrollo → Evidencia → Resultado → Impacto → Transferencia**

## 14. Conclusión

Las evidencias constituyen un elemento fundamental para demostrar que EcoTech Hybrid no es únicamente una propuesta teórica, sino un proyecto desarrollado mediante **experimentación, colaboración interdisciplinar, innovación tecnológica y aprendizaje práctico**.

La organización del repositorio facilita que alumnado, profesorado, entidades colaboradoras y agentes externos puedan consultar, reutilizar y ampliar los materiales generados.

El objetivo final es que cada evidencia contribuya a demostrar una idea central:

> **Un reto real puede convertirse en una experiencia educativa innovadora cuando diferentes competencias profesionales trabajan juntas, incorporan tecnología y documentan el proceso para poder transferirlo y mejorarlo.**
