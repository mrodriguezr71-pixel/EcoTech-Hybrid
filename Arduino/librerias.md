# Librerías y recursos de programación Arduino

## 1. Introducción

Durante la experimentación desarrollada en el proyecto **EcoTech Hybrid – Innovación Verde para un Futuro Sostenible**, se empleó Arduino como plataforma para explorar la adquisición de datos mediante sensores y la automatización de diferentes funciones.

El uso de librerías permite ampliar las funcionalidades de Arduino y facilitar la comunicación con determinados sensores y dispositivos.

---

## 2. Criterio de documentación

La identificación de las librerías utilizadas debe realizarse a partir del código original desarrollado durante la experiencia.

Para garantizar la trazabilidad del proyecto, **no se incorporan en esta documentación librerías concretas que no hayan sido verificadas previamente en el código original**.

Una vez identificados los componentes y el código empleado, este documento podrá completarse con:

* Nombre de la librería.
* Versión utilizada, cuando sea relevante.
* Sensor o dispositivo asociado.
* Función que desempeña.
* Enlace a su documentación oficial.
* Dependencias necesarias.
* Observaciones sobre su instalación.
